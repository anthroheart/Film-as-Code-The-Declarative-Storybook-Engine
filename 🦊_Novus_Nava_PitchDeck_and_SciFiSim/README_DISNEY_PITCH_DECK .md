## 🌟 Overview

The **AnthroHeart Pitch Deck Generator** is an automated, two-stage executive presentation compiler designed to package the vast _AnthroHeart_ universe into multi-generational Disney franchise pitch decks (Feature Animation, Disney+ Series, Theme Parks, Soundtracks, and Interactive Consumer Tech).

Built specifically to handle massive asset libraries (30+ GB of raw artwork, uncompressed WAV masters, and full-length novel databases), the system operates on a **Zero-Waste / Credit-Protected Architecture**:

1. **Stage 1 (Local Preprocessor — $0.00 Cost):** Recursively crawls your raw assets, builds a complete local inventory (`MANIFEST.json`), extracts the creative DNA (`GENOME.yaml`), and downscales presentation images into a lightweight staging cache.
2. **Stage 2 (AI Pitch Architect — ~$0.003 / Run):** Synthesizes executive slide copy and structural layouts using `gpt-4o-mini` by reading _only_ the compact `GENOME.yaml`, safeguarding your OpenAI API balance.
3. **Stage 3 (Dark Mode Theatrical Renderer):** Compiles the pitch into a modern, 16:9 widescreen presentation featuring deep obsidian tones (`#07080c`), glowing gold accents (`#e5b95f`), glassmorphic metrics cards, and print-ready PDF export formatting.

## 🚀 Quickstart Guide

### 1. Installation & Environment Setup

Clone or navigate to your workspace and install the required dependencies:

```bash
pip install openai Pillow pyyaml
```

Set your OpenAI API key:

```bash
# macOS / Linux
export OPENAI_API_KEY="your-api-key-here"

# Windows (PowerShell)
$env:OPENAI_API_KEY="your-api-key-here"
```

---

### 2. Step 1: Scan, Compress & Build Manifest ($0.00 Cost)

Run the local scanner pointing to your root assets folder (e.g., your 33 GB drive):

```bash
python stage_assets_and_manifest.py --source /path/to/your/assets --dest ./anthroheart_deck_assets
```

**What this produces:**

- `./anthroheart_deck_assets/images/`: Downscaled, web-optimized JPEG/PNG artwork sized specifically for slides (avoids memory crashes during PDF export).
- `MANIFEST.json`: Complete index of your audio tracks, novels, poetry books, and web archives.
- `GENOME.yaml`: High-density IP specification storing lore constants, cosmic dimensions (2.2T galaxies, 14T dimensions), character tiers, and franchise pillars.

---

### 3. Step 2: Compile Executive Decks

Run the AI pitch architect to compile your custom presentation decks:

```bash
# Standard run: 14 slides, 2 strategic versions (gpt-4o-mini)
python compile_pitch_deck.py --pages 14 --versions 2

# High-depth run: 24 slides, 4 strategic franchise angles
python compile_pitch_deck.py --pages 24 --versions 4
```

**Built-in Strategic Angles:**

1. **Version 1:** _Executive Studio Vision_ (The next _Frozen_ meets _Avatar_ meets _Zootopia_).
2. **Version 2:** _Deep Metaphysical Lore & Character Arcs_ (The Octave Mirror, Divine Anthro, radical forgiveness).
3. **Version 3:** _Transmedia Ecosystem_ (147 Master Tracks, Disney+ Series, Theme Parks & Intention Tech).
4. **Version 4:** _Radical Forgiveness & Creative Sovereignty_ (The Completion Field).

---

### 4. Step 3: Export to Disney-Quality PDF

1. Open any generated file (e.g., `anthroheart_deck_v1.html`) in **Google Chrome**, **Microsoft Edge**, or **Brave**.
2. Press **`Ctrl + P`** (Windows) or **`Cmd + P`** (macOS) to open the print dialog.
3. Configure the following print settings:
   - **Destination:** `Save as PDF`
   - **Layout:** `Landscape`
   - **Paper Size:** `16:9` or `Tabloid / A3 / Letter`
   - **Margins:** `None`
   - **Options:** Check **`Background graphics`** _(Essential for dark mode styling and luminous gradients)_.
4. Click **Save**.
